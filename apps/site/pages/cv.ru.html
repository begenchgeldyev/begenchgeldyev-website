Pantheon Авг 2026 — наст. время
Пет-проект — TypeScript / Bun

Приватный Telegram-шлюз к среде AI-агентов OpenClaw — общение с несколькими агентами прямо с телефона: авторизация, маршрутизация и один ход агента на сообщение.

  • Маршрутизирует сообщения между агентами; ключи сессии делегируют память разговора самой среде агентов, поэтому шлюз остаётся stateless — без базы данных.
  • Разделён на слои так, что среда агентов доступна через единственный адаптер: Telegram, маршрутизация и логика агентов не протекают друг в друга.
  • Защищён по умолчанию: белый список по числовому id, Bun.spawn() с массивом аргументов вместо строки для шелла и JSON-логи только с метаданными — никогда с телом сообщений.
